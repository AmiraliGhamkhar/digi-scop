# دیجی‌اسکوپ

دیجی‌اسکوپ یک داشبورد فارسی و راست‌به‌چپ برای **ثبت و تحلیل رتبه‌های
مشاهده‌شده** و قیمت محصولات دیجی‌کالاست. این برنامه با FastAPI، SQLAlchemy،
SQLite، جاوااسکریپت ساده و Chart.js ساخته شده است.

> رتبه در دیجی‌اسکوپ یعنی جایگاه کالا در فهرستی که در یک زمان مشخص دریافت شده
> است؛ نه تعداد فروش و نه تخمین فروش. رتبه فعلی هرگز به‌عنوان داده گذشته ذخیره
> نمی‌شود و اجرای ناموفق به‌عنوان غیبت کالا محاسبه نمی‌شود.

راهنمای کامل معماری، API، استقرار، پشتیبان‌گیری و محدودیت‌های داده در
[README انگلیسی](README.md) قرار دارد. گزارش بررسی واقعی MCP نیز در
[`docs/MCP_INTEGRATION_REPORT.md`](docs/MCP_INTEGRATION_REPORT.md) است.

## اجرای سریع

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

سپس `http://127.0.0.1:8000` را باز کنید. مستندات API در `/docs` است.

## جمع‌آوری و آزمون

```bash
# بررسی اتصال MCP
python -m scripts.check_mcp --call-data

# ثبت رتبه فعلی برای محدوده‌های فعال
python -m scripts.collect --limit 20

# داده نمایشی، فقط در محیط development/test
python -m scripts.seed_demo_data

# آزمون‌های قطعی و بدون وابستگی به سرویس زنده
pytest -q
```

برای اجرای دستی API باید `ADMIN_TOKEN` در `.env` تنظیم شود. برای زمان‌بندی،
دستور `python -m scripts.collect` را با cron اجرا کنید؛ برنامه وب عمداً زمان‌بند
داخلی ندارد تا چند worker کار تکراری ایجاد نکنند.

## محدودیت‌های مهم

- ابزار `best_selling` حداکثر ۳۰ نتیجه و هیچ پارامتر صفحه‌ای ندارد؛ بنابراین
  فهرست ۵۰تایی کل بازار ممکن است فقط شامل ۳۰ مشاهده قابل‌دریافت باشد. این کمبود
  شفاف نمایش داده می‌شود.
- تاریخچه رتبه یا تعداد فروش در MCP وجود ندارد. تاریخچه رتبه از نخستین اجرای
  دیجی‌اسکوپ شروع می‌شود.
- `product_price_chart` حدود ۳۰ نقطه روزانه و مستقل برای هر رنگ/مدل می‌دهد؛ این
  داده هرگز به رتبه تاریخی تبدیل نمی‌شود.
- سرویس زنده از محیط محدود ساخت قابل دسترسی نبود. آداپتور بر اساس قرارداد مخزن
  بالادستی پیاده‌سازی و با پاسخ‌های mock آزموده شده است؛ وضعیت میزبان واقعی را با
  `python -m scripts.check_mcp` بررسی کنید.

دیجی‌اسکوپ وابسته یا مورد تأیید دیجی‌کالا نیست. قیمت، موجودی و رتبه ممکن است بعد
از آخرین مشاهده تغییر کنند.
